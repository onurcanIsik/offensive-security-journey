# 2026-11-24 — SQL Injection & Burp Suite

## What I learned

- SQL injection happens when an app puts user input directly into a SQL
  query. The database can't tell my data from its own code, so my SQL runs.
- Practiced: WHERE clause, login bypass, UNION attacks, reading other
  tables via `information_schema`, and blind SQL injection.
- Blind SQLi: the page never shows the data, but it behaves differently
  for true/false conditions ("Welcome back" or not). I extract data one
  character at a time with yes/no questions.
- Burp Suite: Proxy, Repeater, Intruder.

## Key payloads

- Comment out the rest: `' --` (MySQL needs `-- -`)
- Always true: `' OR 1=1 --`
- Login bypass: `administrator'--`
- Read other tables: `' UNION SELECT username, password FROM users--`

## Gotcha

- Burp Community throttles Intruder. My 720-request attack took 4 hours
  and the lab expired before finishing. My own Python script did the same
  job in minutes. Lesson: write your own tools.

## Tool I wrote

- `tools/blind_sql.py` — extracts the admin password character by character
  using the conditional-response oracle.
